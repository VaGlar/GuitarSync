# GuitarSync

A Chrome extension that detects what's playing on Spotify and automatically opens the best-rated chords or tabs for it.

- Greek songs → kithara.to
- Everything else → Ultimate Guitar (top-rated match), with a Google fallback when nothing is found
- Chords/Tabs toggle
- Auto mode: opens/updates a single tab automatically as the song changes
- Recent-searches history, so you can get back to a song after the next one starts
